# Phone Simulator - 3D Maker — 3D симулятор смартфона

**Создай, протестируй и представь свой идеальный смартфон в 3D!** Игра, где ты можешь собрать уникальное устройство, протестировать его возможности в реалистичном симуляторе и похвастаться своим творением друзьям.

[![Google Play](https://img.shields.io/badge/Google_Play-414141?style=for-the-badge&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=com.WetGrass.PhoneSimulator3DMaker)
[![Unity](https://img.shields.io/badge/Unity-100000?style=for-the-badge&logo=unity&logoColor=white)](https://unity.com)

## 🎮 Возможности

- **🔧 Конструктор устройств**: Собери свой уникальный смартфон из множества деталей и компонентов
- **📱 Реалистичный симулятор**: Протестируй готовое устройство в реалистичной среде с рабочим интерфейсом
- **🎨 Кастомизация**: Выбирай цвета, материалы и оформление для своего устройства
- **📊 Система характеристик**: У каждого выбора есть последствия - разные компоненты влияют на производительность
- **🌍 Презентация**: Покажи свое творение друзьям и сообществу
